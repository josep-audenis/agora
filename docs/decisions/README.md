# Decision records

Decision records capture choices that are costly to reverse. Keep records even after a decision is superseded; add a new record that links back.

Use sequential names such as `0002-message-delivery-guarantees.md`. Each record should state status, date, context, decision, alternatives, and consequences. Proposed designs and unresolved questions belong in the relevant topic page until accepted.
